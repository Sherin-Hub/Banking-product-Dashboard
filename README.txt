FINOVA STREAMLIT DASHBOARD

1. Install Python if it is not already installed.
2. Open this folder in VS Code.
3. Open Terminal in this folder.
4. Run: py -m pip install -r requirements.txt
5. Run: py -m streamlit run app.py
6. Open the Local URL printed in the terminal (usually http://localhost:8501).

The original HTML/CSS/JavaScript dashboard is embedded in Streamlit. The banking data is demo data; there is no backend or persistent storage.
